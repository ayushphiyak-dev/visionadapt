# 👁️ VisionAdapt

**VisionAdapt** is an interactive web application that helps demonstrate how personalized color vision correction can improve accessibility for gamers with color vision deficiencies. The project combines an engaging landing page, an accessibility assessment, a modern dashboard, and real-time visual simulations into a single lightweight web application.

Designed as a concept prototype, VisionAdapt showcases how accessibility-focused technologies can create a more inclusive gaming experience.

## ✨ Features

- Interactive landing page
- Color vision assessment
- Analytics dashboard
- Live color correction simulation
- Light & Dark mode
- Responsive design

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- SVG
- Canvas API
- Local Storage
