# EduWatch - Student Complaint & Accountability System

A production-ready web application for transparent complaint management in educational institutions.

## 🎯 Overview

EduWatch is a comprehensive platform that empowers students to report, track, and resolve issues at their educational institutions. Built with modern web technologies, it provides a transparent and accountable system for managing complaints with AI verification.

## ✨ Features

### Core Functionality
- **Anonymous Reporting**: Submit complaints with optional anonymity
- **AI Verification**: Automated complaint analysis and categorization
- **Real-time Tracking**: Monitor complaint status from submission to resolution
- **Multi-role Support**: Student, Institute Admin, Government Official, and Platform Admin roles
- **Community Confirmation**: Students can confirm similar issues
- **Response Management**: Institutes can respond and update complaint status

### Technical Features
- **Next.js 14 App Router**: Modern React framework with server components
- **TypeScript**: Full type safety throughout the application
- **Tailwind CSS**: Utility-first styling with custom design system
- **Framer Motion**: Smooth animations and transitions
- **Mock Authentication**: LocalStorage-based auth system for demo
- **Responsive Design**: Mobile-first approach (320px to 1440px+)

## 🚀 Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Components**: Radix UI, shadcn/ui patterns
- **Icons**: Lucide React
- **Animations**: Framer Motion

## 🔧 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
