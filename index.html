Four systems. One clear picture.

Each accessibility layer solves a different failure mode of color vision deficiency — used together, or dialed in individually.

Color remapping

Every frame is re-projected through your personal LMS confusion profile so reds, greens, and browns pull apart again.

Contrast enhancement

Adaptive luminance boosting keeps UI elements and health bars readable without blowing out the rest of the scene.

Adaptive outlines

Enemies, pickups and hazards get a dynamic outline whose thickness and hue shift based on background contrast.

Texture overlays

Same-color surfaces get subtle procedural texture so terrain, teams, and resources stay distinguishable by pattern.

Icon overlays

Team, item and status colors get a redundant icon layer, matching the icon language of the specific title.

Real-time engine

A WebGL shader pipeline applies your profile at native frame rate, so there's zero perceptible input lag.

How VisionAdapt works

From a short clinical-style assessment to a live shader running in your browser.

1

Take the assessment

A short set of Ishihara-style plates and preference questions, scored the same way a clinical screening would be.

2

Build your profile

We classify deficiency type and severity, then generate a personalized LMS color-confusion matrix.

3

Install the extension

The Chrome extension detects supported titles and applies your profile through a live WebGL/SVG shader pass.

4

Fine-tune anytime

Adjust contrast, outline thickness, and overlay density from the dashboard — changes apply instantly, in-game.
